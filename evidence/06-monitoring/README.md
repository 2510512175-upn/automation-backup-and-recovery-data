# Bukti Monitoring Anggota 6

Simpan bukti asli pengujian T15 dan T16 pada VM Ubuntu kelompok di direktori ini.

Bukti yang perlu disertakan:

- T15: PID proses backup, keluaran CPU/memori/RSS, dan baris `TYPE=PROCESS` dari `logs/monitoring.log`.
- T16: PID numerik yang tidak ditemukan, pesan penolakan, exit status `1`, dan baris `STATUS=REJECTED` tanpa metrik CPU/memori.

Jangan mengisi hasil aktual atau memberi status lulus sebelum pengujian benar-benar dilakukan. Hasil pengujian otomatis pada salinan sementara bukan pengganti screenshot dari VM Ubuntu kelompok.
